LaTeX Mobile: modified LaTeX base distribution

Based on LaTeX release-2021-11-15-PL1, upstream commit
6c71902738ec896e508cb580bb2b3152b7ad8bec.
The original copyright notices and LPPL terms continue to apply.

latex.ltx contains an inherited Tectonic modification: the missing-file
handler issues a fatal error instead of prompting for a replacement filename.
The bundled comment attributes this change to Tectonic; we have not identified
its original patch commit. LaTeX Mobile adds a header identifying this modified
file and referring to this notice, and prefixes the format banner with
"LaTeX Mobile modified" to identify the modified distribution when used. These changes do not relicense LaTeX as MIT.

The bundle is a subset selected by the profile's example documents. Its
manifest.json lists the distributed files. For profiles without the languages
feature, language.dat is replaced with an English-only configuration.
For full/language-enabled profiles, Czech, Indonesian, Macedonian, Latvian, and Armenian entries
load the project-authored empty lm-nohyphen.tex instead of upstream patterns.
Their original pattern files and loaders are excluded.
Entries previously using zerohyph.tex or dumyhyph.tex also use the project
empty loader. No-hyphenation behavior is retained; the diagnostic dumylang
entry no longer loads the two dummy test patterns.

l3backend-xetex.def is based on the upstream l3backend 2022-02-07 release.
An inherited Tectonic patch replaces the extractbb shell version query with
constant 20210318. LaTeX Mobile retains that compatibility value for XDV
specials, adds a modification header, and identifies the modified backend in
its package description. This does not mean the PDF renderer is xdvipdfmx.
The exact inherited difference is recorded in
experiments/licenses/l3backend-xetex.def.patch.
Complete unmodified upstream source:
https://github.com/latex3/latex3/releases/download/2022-02-07/l3backend-ctan.zip
